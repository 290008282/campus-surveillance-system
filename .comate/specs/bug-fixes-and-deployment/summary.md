## 部署步骤

### 快速部署
```bash
# 1. 生成安全密钥
bash generate-secrets.sh

# 2. 配置环境变量
cp .env.example .env
vi .env  # 编辑密钥和配置

# 3. 执行部署
chmod +x deploy.sh
./deploy.sh
```

### 手动部署
```bash
# 1. 上传到服务器
scp -r . root@192.168.0.254:/opt/campus-surveillance-system

# 2. SSH登录
ssh root@192.168.0.254

# 3. 启动服务
cd /opt/campus-surveillance-system
docker-compose build --no-cache
docker-compose up -d
```
